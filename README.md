# arduino-projects
A collection of hardware projects built using the Elegoo UNO R3 starter kit.
Built as part of my electrical engineering undergraduate journey at UH.


### 1. LED Blink
Control an LED using digital output. First introduction to circuits, Ohm's Law, and Arduino programming.
- Concepts: Digital output, Ohm's Law, resistors, breadboard wiring
- Components: LED, 220Ω resistor, Arduino UNO

### 2. Active Buzzer
Make a buzzer beep using digital control.
- Concepts: Digital output, active vs passive components
- Components: Active buzzer, Arduino UNO

### 3. Passive Buzzer — Songs
Play musical notes and songs using PWM frequency control.
- Songs: Nokia ringtone, Harry Potter, Star Wars, Super Mario Bros, Fur Elise
- Concepts: PWM, frequency, square wave oscillation
- Components: Passive buzzer, Arduino UNO

### 4. Ultrasonic Distance Sensor (HC-SR04)
Measure distance in real time using sound waves.
- Concepts: Sound wave timing, libraries, serial monitor output
- Components: HC-SR04 sensor, Arduino UNO

### 5. RGB LED
Mix colors using PWM to control red, green and blue brightness independently.
- Concepts: PWM, analog output, color mixing
- Components: RGB LED, 3x 220Ω resistors, Arduino UNO

### 6. Digital Inputs — Button Control
Use two buttons to turn an LED on and off.
- Concepts: Digital input, INPUT_PULLUP, conditional logic
- Components: 2x buttons, LED, Arduino UNO

### 7. Tilt Switch
Detect orientation using a tilt ball switch. Combined with buzzer for audio feedback.
- Concepts: Digital input, sensor reading, multi-component integration
- Components: Tilt switch, buzzer, LED, Arduino UNO
